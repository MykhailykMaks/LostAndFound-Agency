# Lost and Found Agency Information System

A relational database system designed with **C# WPF** and **Entity Framework Core** to automate the tracking and matching of lost and found items.

## 📌 Project Overview
Developed as an academic project on Database Organization, this system provides a desktop interface and robust database architecture for managing lost property lifecycles, ensuring data integrity and secure access.

### Key Features
- **Relational Data Architecture:** Implemented precise ER data modeling adhering to Third Normal Form (3NF).
- **Matching Algorithms:** Engineered role-based matching algorithms to cross-reference lost items with found inventory.
- **Access Control:** Integrated role-based access control (RBAC) to separate standard operational intake from administrative oversight.
- **Desktop UI:** User-friendly frontend built with XAML/WPF.

## 🛠 Tech Stack
- **Language:** C# (.NET)
- **UI Framework:** Windows Presentation Foundation (WPF)
- **Data Access:** Entity Framework Core
- **Database:** Microsoft SQL Server
